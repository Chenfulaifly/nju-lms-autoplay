# nju-lms-autoplay

适用于南京大学 LMS（智汇南雍）和超星学习通的 Tampermonkey 用户脚本。它会接管课程视频播放、尽量维持后台计时，并在视频完整播放后进入下一节。

> 本项目用于减少重复的页面操作，不代表平台官方功能。请遵守学校、课程及学习平台的相关规定，并确认自动播放符合课程要求。脚本无法保证平台一定认定相应学习进度。

## 支持平台

| 平台 | 匹配地址 | 播放方式 | 下一节方式 |
| --- | --- | --- | --- |
| 南京大学 LMS | `https://lms.nju.edu.cn/*`、`https://*.nju.edu.cn/course/*` | 点击平台原生播放按钮 | 返回课程目录，打开下一项未完成内容 |
| 超星学习通 | `https://*.chaoxing.com/*` | 调用页面视频播放器，并处理嵌套 iframe | 点击左侧目录或播放器“下一节”按钮；iframe 可通知顶层页面翻页 |

## 主要功能

- 视频播放到接近 **100%**（代码阈值为 `99.9%`）或触发 `ended` 后自动进入下一节。
- 后台保护默认开启，切换标签页或窗口失焦时尝试继续播放和计时。
- 通过悬浮面板开始/停止连播、手动进入下一节、开关后台保护。
- 按平台或课程在浏览器本地保存运行状态。
- 在面板中显示后台事件拦截、请求字段修正和自动续播次数。
- 不快进视频，不直接修改视频的 `currentTime`。

## 安装

### 1. 安装用户脚本管理器

在 Chrome、Edge 或 Firefox 中安装 [Tampermonkey](https://www.tampermonkey.net/)；其他兼容的用户脚本管理器也可以尝试使用。

### 2. 导入脚本

1. 打开 Tampermonkey 管理面板；
2. 选择“添加新脚本”；
3. 删除编辑器中的默认内容；
4. 复制 [`nju-lms-autoplay.user.js`](./nju-lms-autoplay.user.js) 的全部内容并粘贴；
5. 保存脚本，然后刷新课程页面。

## 自定义匹配网址与播放阈值

教学使用者可以直接在 Tampermonkey 中编辑已安装的脚本。修改完成后请保存脚本，并刷新所有已经打开的课程页面。

### 增加可匹配的网址

脚本顶部的用户脚本元数据中，`@match` 决定脚本会在哪些页面加载：

```javascript
// @match        https://lms.nju.edu.cn/*
// @match        https://*.nju.edu.cn/course/*
// @match        https://*.chaoxing.com/*
```

要增加网址，请在同一区域新增一行。例如：

```javascript
// 精确匹配一个教学平台域名下的全部页面
// @match        https://lms.example.edu.cn/*

// 匹配 example.edu.cn 的任意子域名，但只加载 course 路径
// @match        https://*.example.edu.cn/course/*
```

`@match` 的基本格式为：

```text
协议://主机名/路径
```

- `https://` 表示只匹配 HTTPS 页面；如果平台仍使用 HTTP，需要另外增加一条 `http://...` 规则；
- 主机名中的 `*.` 表示任意子域名；
- 路径末尾的 `*` 表示匹配该路径下的所有页面；
- 每条规则单独占一行，可同时保留多条 `@match`。

需要注意：增加 `@match` **只代表允许脚本在该网址运行，并不会自动完成新平台适配**。

- 如果新增网站与南大 LMS 使用相同页面结构，并且课程路径仍为 `/course/<数字课程 ID>`，现有南大逻辑通常可以直接尝试；
- 如果课程 ID、播放器按钮、目录元素或完成状态文案不同，还需要修改 `COURSE_ID`、`nativePlayButton()`、`activityRows()` 等识别逻辑；
- 超星模式还会检查域名是否以 `chaoxing.com` 结尾。若学校将同一套页面部署在其他域名，需要同时修改 `IS_CHAOXING` 的域名判断，不能只增加 `@match`；
- 播放器位于 iframe 时，iframe 自身的网址也必须被 `@match` 覆盖，否则脚本无法进入该 frame 执行。

建议先使用精确域名和精确路径，确认正常后再扩大通配范围。匹配范围过宽会让脚本在无关页面中安装可见性、网络请求和播放器补丁。

### 修改播放阈值

在脚本中搜索 `AUTO_ADVANCE_RATIO`：

```javascript
const AUTO_ADVANCE_RATIO = 0.999; // 播到 100% 才算完成
```

该值使用 `0` 到 `1` 之间的小数表示播放比例：

| 设置值 | 自动进入下一节的时机 |
| --- | --- |
| `0.85` | 播放到 85% |
| `0.90` | 播放到 90% |
| `0.95` | 播放到 95% |
| `0.999` | 播放到约 99.9%，当前默认值 |

例如，希望视频播放到 90% 后进入下一节，可改为：

```javascript
const AUTO_ADVANCE_RATIO = 0.90;
```

不建议设置为严格的 `1`：部分播放器的时长存在浮点误差，最后一次 `timeupdate` 可能无法满足“当前时间 ÷ 总时长等于 1”，从而只能等待 `ended` 事件。阈值设置过低也可能导致平台尚未记录为完成；建议教学使用者根据实际平台规则，在 `0.95` 到 `0.999` 之间调整并先用一节课程测试。

播放阈值只控制何时开始换课流程，不会改变视频播放速度或拖动播放进度。达到阈值后，南大 LMS 默认再等待 3 秒，超星默认等待 4 秒，以便平台同步最后一段进度。

> Tampermonkey 中保存的是脚本副本。修改 GitHub 仓库里的文件不会自动更新已经安装的副本，反之亦然；需要重新复制、安装或手动同步修改。

## 使用方法

### 南京大学 LMS

1. 打开课程视频页；
2. 在右下角“课程连播”面板中点击“开始连播”；
3. 脚本通过平台原生播放按钮启动当前视频；
4. 视频播放完成后，脚本等待平台同步进度，再返回目录并打开下一项未完成内容。

如果浏览器阻止有声自动播放，请按面板提示手动点击一次平台原有的播放按钮。

### 超星学习通

1. 打开包含课程目录和视频播放器的学习页面；
2. 在顶层页面右下角点击“开始连播”；
3. 视频模块 iframe 会自动尝试接管播放器；
4. 视频结束后等待 4 秒：若平台已经自动播放下一节，脚本不会重复翻页；否则会尝试点击下一节。

超星播放器 iframe 中默认启用自动播放逻辑，但控制面板只显示在顶层页面。如果自动播放被浏览器拦截，请手动点击一次视频中央的播放按钮。

## 控制面板

| 按钮 | 作用 |
| --- | --- |
| 开始连播 / 停止连播 | 开启或停止当前平台/课程的自动连播 |
| 直接进入下一节 | 跳转到下一项；不会修改当前项目的完成状态 |
| 后台保护：开 / 关 | 控制失焦保护、暂停拦截和请求字段修正 |

面板底部统计：

- **拦截**：被阻止传递给页面的隐藏、失焦等事件数量；
- **改写**：被修正的进度/心跳请求数量；
- **续播**：因失焦暂停后自动恢复播放的次数。

这些计数仅存在于当前页面，刷新后重新计算。

## 工作原理

脚本在 `document-start` 阶段运行，主要分为以下模块。

### 1. 后台播放守护

- 将 `document.hidden`、`visibilityState` 和 `hasFocus()` 呈现为前台状态；
- 在捕获阶段拦截 `visibilitychange`、`blur`、`freeze` 等事件；
- 将 `IntersectionObserver` 的结果呈现为元素仍在视口内；
- 在真实失焦后的短时间内阻止页面主动调用 `video.pause()`；
- 若播放器仍被暂停，最多尝试自动续播 5 次；
- 每 30 秒派发一次鼠标移动事件，降低页面因长时间无操作而中断的概率。

用户主动点击或按键后的 4 秒内，脚本不会把暂停判断为后台中断，以免立即推翻手动暂停操作。

### 2. 进度请求修正

脚本包装了页面的 `fetch`、`XMLHttpRequest` 和 `sendBeacon`。当请求地址看起来与心跳、播放或学习进度有关时，会检查字符串请求体，并修正与隐藏、焦点、前台状态有关的字段。

在超星页面中，还会将表单请求中的：

- `isdrag` 调整为 `0`；
- `view` 调整为 `1`。

脚本只处理平台页面原本发出的请求，不会主动把课程信息发送给第三方服务器。

### 3. 站点识别与状态保存

- 南大 LMS：从 `/course/<课程 ID>` 中识别课程，并使用 `nju-lms-autoplay-v1:<课程 ID>` 保存连播状态；
- 超星学习通：使用 `autoplay:chaoxing` 保存状态，并识别顶层页面、播放器 iframe 和常见视频模块地址；
- 后台保护开关使用 `nju-lms-guard-v1` 保存。

所有状态都保存在当前网站的 `localStorage` 中。

### 4. 播放器接管

- 南大 LMS 使用平台原生播放按钮，避免只调用 `<video>.play()` 而没有进入平台自身的计时流程；
- 超星直接调用视频元素的 `play()`，并递归查找最多 3 层同源 iframe 中的视频；
- 两个平台共用 `play`、`pause`、`timeupdate` 和 `ended` 事件监听；
- 达到 99.9% 时即按完整播放处理，避免因为播放器浮点时间误差永远无法严格达到 100%。

### 5. 自动进入下一节

南大 LMS 会返回课程目录，从当前项目之后查找第一项没有标记为“已完成”的可点击内容。

超星按以下顺序尝试：

1. 点击左侧目录中当前节点之后的下一个可见节点；
2. 点击播放器或页面中的“下一节”按钮；
3. 如果播放器位于 iframe，通过 `postMessage` 通知顶层页面执行上述操作。

脚本还会设置超星本地配置 `videoAutoPlay=true`，让平台自身的自动下一集机制作为补充。

## 注意事项

- “播放到 100%”和“自动进入下一节”不等于平台一定判定为完成，最终状态以平台记录为准。
- 南大目录逻辑不会额外判断下一项是否为视频；如果下一项是测验、文档等内容，连播可能停在“正在等待视频”，需要手动处理。
- 超星页面存在多种版本和嵌套结构；跨域 iframe 无法被脚本直接读取，届时可能需要手动播放或翻页。
- 浏览器的节能策略、标签页冻结、网络中断或电脑睡眠仍可能暂停播放或影响进度上传。
- 浏览器生成的鼠标事件不是可信用户事件，平台若检查 `isTrusted`，模拟活动可能不会生效。
- 请求修正只覆盖字符串形式的 JSON 或表单请求体，不覆盖所有 `Request`、`Blob`、`FormData` 等情况。
- 平台更新 DOM、路由、按钮文案或接口后，播放器和目录选择器可能失效。
- 后台保护会改写当前页面的可见性相关行为；页面异常时，请先关闭后台保护并刷新。

## 常见问题

### 面板一直显示“等待你点击播放”

浏览器阻止了有声自动播放。请手动点击一次平台原有的播放按钮。完成首次交互后，后续视频通常可以自动启动。

### 超星页面没有显示面板

面板只显示在顶层页面，不显示在播放器 iframe 中。请确认你打开的是完整课程页面，而不是单独的播放器地址。

### 视频播完后没有进入下一节

先检查目录是否已展开、下一项是否可点击，以及平台是否已经自行切换播放器。页面结构变化时，脚本可能无法找到 `.posCatalog_select` 或“下一节”按钮。

### 手动暂停后又被自动播放

脚本会在最近一次点击或按键后的 4 秒内尊重手动暂停。如果需要长时间暂停，建议先点击“停止连播”或关闭后台保护。

### 如何恢复平台默认行为

在 Tampermonkey 中停用或删除本脚本，然后刷新课程页面。脚本不会修改服务器配置，只在对应网站的浏览器本地存储中保留开关状态。
