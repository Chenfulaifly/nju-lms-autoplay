# nju-lms-autoplay

适用于南京大学 LMS（智汇南雍）的 Tampermonkey 用户脚本。它通过平台原生播放器连续播放课程视频，在达到设定进度后返回课程目录，并自动打开下一节未完成内容。

> 本项目仅用于减少重复的页面操作。请遵守学校、课程与学习平台的相关规定，并确认自动播放符合你的课程要求。脚本不能保证平台一定认定相应学习进度。

## 主要功能

- 通过平台原生播放按钮启动视频，尽量保持平台原有的播放与进度记录流程。
- 当前视频播放到 **85%** 或自然结束后，自动进入下一节未完成课程。
- 达到 85% 后额外等待 3 秒，为平台同步最后一段进度预留时间。
- 按课程保存连播状态，刷新页面或切换课程页面后可继续运行。
- 提供悬浮控制面板，可开始/停止连播、手动进入下一节、开关后台保护。
- 后台保护默认开启：在切换标签页或窗口失焦时，尝试维持播放与计时。
- 在面板中显示后台事件拦截、请求字段修正和自动续播次数。

## 工作原理

脚本由两个相对独立的部分组成。

### 自动连播

在 `/course/<课程 ID>/...` 页面中，脚本会：

1. 查找页面中的 `<video>` 和平台原生播放按钮；
2. 监听 `play`、`pause`、`timeupdate` 与 `ended` 事件；
3. 播放进度达到 85% 后返回课程目录；
4. 从目录 DOM 中读取课程项目，跳过标记为“已完成”的项目；
5. 打开当前项目之后的下一节未完成课程。

连播状态保存在浏览器 `localStorage` 中，键名包含课程 ID，因此不同课程之间互不影响。

### 后台保护

脚本在 `document-start` 阶段安装后台保护，包括：

- 将页面可见性和焦点状态呈现为前台状态；
- 拦截 `visibilitychange`、`blur`、`freeze` 等事件；
- 将 `IntersectionObserver` 的结果呈现为元素仍在视口内；
- 在失焦后的短时间内阻止页面主动暂停视频，并在必要时尝试续播；
- 修正平台既有进度请求中与可见性、焦点有关的字段；
- 定期派发鼠标移动事件，避免页面因长时间无操作而中断。

后台保护可以在悬浮面板中随时关闭。它只修改当前页面的运行行为，不会向第三方服务发送数据。

## 安装

### 1. 安装用户脚本管理器

在 Chrome、Edge 或 Firefox 中安装 [Tampermonkey](https://www.tampermonkey.net/)（也可使用兼容的用户脚本管理器）。

### 2. 导入脚本

1. 打开 Tampermonkey 管理面板；
2. 选择“添加新脚本”；
3. 删除编辑器中的默认内容；
4. 复制 [`nju-lms-autoplay.user.js`](./nju-lms-autoplay.user.js) 的全部内容并粘贴；
5. 保存脚本。

### 3. 开始使用

1. 打开南京大学 LMS 的课程视频页并刷新；
2. 在右下角找到“课程连播”面板；
3. 点击“开始连播”；
4. 如果浏览器阻止有声自动播放，按面板提示手动点击一次平台原有的播放按钮。

## 面板按钮

| 按钮 | 作用 |
| --- | --- |
| 开始连播 / 停止连播 | 开启或停止当前课程的自动连播 |
| 直接进入下一节 | 返回目录并打开下一节未完成课程；不会修改当前项目的完成状态 |
| 后台保护：开 / 关 | 控制失焦保护、暂停拦截和请求字段修正 |

面板底部的三个计数分别表示：被拦截的后台事件数、被修正的请求数，以及自动续播次数。这些计数只保存在当前页面内，刷新后会重新计算。

## 适用范围

用户脚本当前匹配：

```text
https://lms.nju.edu.cn/*
https://*.nju.edu.cn/course/*
```

自动连播只会在路径符合 `/course/<数字课程 ID>` 时启动；后台保护会在上述匹配页面加载时生效。

## 注意事项

- 脚本不会快进视频，也不会直接修改视频的 `currentTime`。
- “播放到 85%”是自动换课阈值，不等同于平台一定判定为完成；实际规则以平台和课程要求为准。
- “直接进入下一节”只执行页面跳转，不会伪造当前课程的完成记录。
- 浏览器的节能策略、标签页冻结、网络中断或电脑睡眠仍可能暂停播放或影响进度上报。
- 平台页面结构、路由、按钮文案或接口变化后，目录识别与自动播放可能失效。
- 后台保护会改写页面可见性相关行为；如果页面出现异常，请先在面板中关闭后台保护，再刷新页面。

## 常见问题

### 面板一直显示“等待你点击播放”

浏览器阻止了有声自动播放。请手动点击一次平台原有的播放按钮，后续课程通常可以继续自动启动。

### 找不到下一节课程

先确认课程目录已经正常加载。若仍提示“未找到课程”，请刷新页面；如果平台近期更新了页面结构，脚本中的目录选择器可能需要同步调整。

### 手动暂停后又被自动播放

脚本会尽量尊重最近的点击或按键操作，但平台自身的暂停事件与失焦事件可能同时发生。需要长时间手动暂停时，建议先点击“停止连播”或关闭后台保护。

### 如何彻底恢复默认行为

在 Tampermonkey 中停用或删除本脚本，然后刷新 LMS 页面。脚本仅在浏览器本地保存连播和后台保护开关，不会修改服务器端配置。

## 开发与检查

项目无需构建，主文件是 [`nju-lms-autoplay.user.js`](./nju-lms-autoplay.user.js)。修改后可用 Node.js 做基础语法检查：

```bash
node --check nju-lms-autoplay.user.js
```

当前版本：`2.0.0`

## 隐私说明

脚本不收集个人信息，不连接第三方统计或分析服务。它会拦截并可能修改 LMS 页面原本发出的部分进度/心跳请求，但不会自行把课程信息发送到其他服务器。
